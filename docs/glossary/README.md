# Glossary

This directory defines the terms used in Cloud Foundry documentation and in the Docs Working Group's own records, so that the same thing has the same name everywhere. Changing a term across the content repositories takes one pull request per repository, so it is cheaper to agree on a term before it spreads.

The glossary covers two kinds of term:

- **Product terms:** Cloud Foundry concepts as the content names them.
- **Documentation terms:** the words used for creating and publishing the documentation, such as book, content repository, template variable, and subnav.

## Entry format

Each entry gives:

- the term, as it should be written
- a definition of one or two sentences
- terms to avoid in its place, if any
- a link to where the term is defined or decided, if it is defined elsewhere

How to write and style content is a matter for the [style guide](../style-guide/README.md); the glossary decides only which word to use.
