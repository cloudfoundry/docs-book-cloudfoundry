# Open Questions

This directory holds questions that the Docs Working Group cannot answer on its own, usually ones that need subject-matter experts before the documentation can be corrected.

## Format

Each file collects the questions from one review or audit, and says at the top what was reviewed and when. Each question has:

- an ID and a short title, for example `INC-01 — Contradictory guidance on RESTRICTED stacks and restaging`
- the affected files
- the discrepancy that was found
- the question to answer, and who is asked

When a question is answered, add the answer under it, with a link to the pull request that corrects the documentation.
