# Style Guide

This directory holds the Cloud Foundry documentation style guide: the current rules for writing and styling content, such as voice and wording, headings, tables, notes, code blocks, and links. Writers and reviewers use it when they create or review a page.

## Style guide or ADR?

The style guide and the [ADRs](../adrs/README.md) can cover the same subject in different ways:

| | Style guide | ADR |
|---|---|---|
| Says | What to do now: the rule, with an example | Why a rule or practice was chosen: its context, the decision, its consequences, and the alternatives considered |
| Changes | Edited in place when a rule changes | Not rewritten; a new ADR supersedes it |
| Read by | Anyone writing or reviewing content | Anyone asking why the documentation works the way it does |

A significant change to a rule starts as an [RFC](../rfcs/README.md) or an ADR. Once it is accepted, a pull request updates the style guide and links to the RFC or ADR. Small fixes, such as a clearer example or a typo, go straight to the style guide.

Which word to use for a thing is a matter for the [glossary](../glossary/README.md); how to write and style it is a matter for the style guide.
